القوانين العامة

القواعد التنظيمية الأساسية لـ Dark Matter

القوانين العامة

  • احترام الإدارة وجميع الأعضاء بشكل كامل.
  • يمنع استخدام البرامج المساعدة أو الثغرات.
  • الالتزام بتعليمات الإدارة.
  • التعاون مع أعضاء المجتمع.

قوانين المتجر والخدمات

  • الالتزام بتسليم الطلبات بالمواصفات المتفق عليها.
  • يمنع إعادة بيع المنتجات دون إذن.
  • احترام حقوق الملكية الفكرية.
  • التواصل عبر التذاكر الرسمية.

قوانين الدعم الفني

  • شرح المشكلة بشكل واضح داخل التذكرة.
  • يمنع فتح تذاكر وهمية.
  • الالتزام بآداب الحوار.
  • تأكيد استلام الطلب بعد الانتهاء.

قوانين الأمان والحماية

  • الحفاظ على سرية بيانات الحساب.
  • تفعيل التحقق بخطوتين.
  • الإبلاغ عن المشاكل الأمنية.
  • التعاون مع الإدارة.
