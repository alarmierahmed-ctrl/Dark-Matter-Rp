DARK MATTER - SUPABASE SETUP

1) أنشئ مشروع في Supabase.

2) افتح SQL Editor، وافتح الملف:
   supabase-setup.sql
   غيّر:
   YOUR_OWNER_EMAIL@example.com
   إلى إيميلك أنت، ثم Run.

3) في Supabase:
   Project Settings > API
   خذ:
   - Project URL
   - anon public key

4) افتح index.html وابحث عن:
   PUT_SUPABASE_URL_HERE
   PUT_SUPABASE_ANON_KEY_HERE
   واستبدلهم ببيانات مشروعك.

5) في Supabase:
   Authentication > Providers > Discord
   فعّل Discord وضع Client ID و Client Secret من Discord Developer Portal.

6) انسخ Callback URL الذي يعطيك Supabase داخل إعداد Discord OAuth2 Redirects.

7) في Supabase:
   Authentication > URL Configuration
   Site URL:
   https://alarmierahmed-ctrl.github.io/Dark-Matter-Rp/
   وأضف نفس الرابط في Redirect URLs.

النتيجة:
- أنت فقط يظهر لك: "مشرفين الموقع".
- تضيف بريد المشرف بزر +.
- المشرف الذي أضفته يظهر له: "الطلبات".
- كل المشرفين يرون نفس الطلبات من أي جهاز.
- كل طلب يظهر بالتاريخ والوقت.
- المشرف يستطيع استلام الطلب وتغيير حالته.
- المشتري يرى طلباته الخاصة فقط من الملف الشخصي.
- لاحقاً نربط ميسّر ليتم تغيير payment_status بعد نجاح الدفع الحقيقي.


مهم:
- مجلد images لازم ترفعه مع index.html.
- النسخة الحالية تُظهر زر "مشرفين الموقع" في القائمة دائماً حتى تقدر تشوفه.
- الإضافة/الحذف الحقيقي للمشرفين لا يعمل إلا بعد ربط Supabase وتسجيلك كصاحب الموقع في site_admins.
