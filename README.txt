Dark Matter — نظام إدارة المتجر للمشرفين

جاهز على نفس نسخة موقعك الحالية.

المزايا:
- زر «إدارة المتجر» يظهر فقط لصاحب الموقع أو مشرف الموقع.
- إنشاء / تعديل / حذف أكواد خصم.
- خصم نسبة مئوية أو مبلغ ثابت + حد أدنى + تاريخ بداية/نهاية + أقصى استخدام.
- تعديل اسم ووصف وإعلان المتجر وتشغيل/إيقاف المتجر.
- تعديل أسعار السيارات.
- إضافة سيارات ومنتجات جديدة.
- حذف وإخفاء المنتجات.
- السعر الرسمي يؤخذ من Supabase عند إنشاء الطلب، وليس من متصفح العميل.

طريقة التركيب:
1) افتح Supabase > SQL Editor.
2) الصق محتوى setup-store-supervisors.sql واضغط Run.
3) ارفع index.html الموجود هنا بدل index.html القديم في GitHub.
4) سجل دخولك بالديسكورد. إذا حسابك Owner أو Supervisor يظهر زر «إدارة المتجر».

مهم:
- لا تضف service_role أو أي Secret داخل index.html.
- الصور الجديدة: ضع رابط مباشر للصورة في خانة رابط الصورة.
- النسخة تعتمد على جداول site_admins و supervisors و orders الموجودة في موقعك الحالي.
