Dark Matter RP - النسخة الكاملة الجديدة

1) ارفع index.html في جذر GitHub Repository باسم index.html.
2) افتح Supabase > SQL Editor وشغّل setup.sql مرة واحدة.
3) في Supabase Authentication تأكد Discord Provider مفعّل، و Site URL هو:
   https://alarmierahmed-ctrl.github.io/Dark-Matter-Rp/
4) لا تحتاج مجلد صور للرئيسية؛ الصور مدمجة داخل index.html.

النسخة تشمل:
- صور الرئيسية الجديدة مدمجة داخل الملف.
- إزالة الهليكوبتر وطاولة التصنيع.
- إضافة إلى السلة بدل شراء/حجز.
- بعد تأكيد الطلب تظهر رسالة: افتح تكت المتجر لاستلام الطلب.
- قسم عنّا داخل الرئيسية + حقوق Dark Matter RP.
- ألوان رئيسية محدثة.
- لوحة إدارة المتجر للمشرفين: تعديل المتجر، السيارات، الأسعار، الصور، ترتيب الظهور، الإضافة والحذف، أكواد الخصم، رابط التكت والرسالة، فتح/إغلاق المتجر.
- رفع صور المنتجات من الجهاز مباشرة إلى Supabase Storage.
